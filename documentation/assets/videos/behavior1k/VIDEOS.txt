Behavior-1K (OmniGibson) demo videos
====================================

Two MP4s per task name:

  docs/assets/videos/behavior1k/<task_name>_unsafe.mp4
  docs/assets/videos/behavior1k/<task_name>_safe.mp4

Examples: shelve_item_unsafe.mp4, shelve_item_safe.mp4

Tracked in regular git (no Git LFS).

Thumbnails for the docs bench page:
  docs/assets/videos/thumbnails/behavior1k/<task>_{unsafe,safe}.jpg

Regenerate after adding or replacing MP4s:
  python scripts/generate_video_thumbnails.py
