RoboCasa demo videos
====================

Two MP4s per task name (same <task_name> as in docs/oopsiebench.md):

  docs/assets/videos/robocasa/<task_name>_unsafe.mp4
  docs/assets/videos/robocasa/<task_name>_safe.mp4

Examples: pick_egg_unsafe.mp4, pick_egg_safe.mp4

Tracked in regular git (no Git LFS).

Thumbnails: docs/assets/videos/thumbnails/robocasa/<task>_{unsafe,safe}.jpg
Regenerate: python scripts/generate_video_thumbnails.py
