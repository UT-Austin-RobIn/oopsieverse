# OopsieVerse

OopsieVerse is a **damage-aware**, **simulator-agnostic** framework and benchmark for evaluating and learning safer policies in rich simulation environments.

Use the tabs above to **install** the stack, follow a **quickstart**, read about **DamageSim**, browse **OopsieBench** tasks, or fix common issues under **Troubleshooting**.

!!! note "Where this site is published"

    When deployed from the `website` branch, this documentation lives under the **`documentation/`** path next to the project’s main marketing site (for example `https://<owner>.github.io/<repo>/documentation/`).
